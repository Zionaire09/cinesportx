Rabbitv3 CSP sandbox server test

This page tests each of rabbitv3’s stream sources inside the separate Pages wrapper. Only the test iframe is sandboxed by the Pages response header; rabbitv3’s production player remains direct.

A provider may detect the inherited sandbox and refuse playback. This experiment blocks popups; it does not proxy or carry the media traffic through Cloudflare Pages.

The selected stream URL is allowlisted by the wrapper and loaded at /wrapper?url=…. Testing does not change any source setting in the main app.
